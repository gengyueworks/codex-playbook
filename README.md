# Codex Playbook

> **一个文科生的 Codex 实战手册** · 不会写代码，也能用 Codex 把事干成。
> A non-programmer's field-tested Codex playbook — no CS degree required.

**我一周前刚注册 GitHub，不会写代码，用 Codex 建了 100+ 个仓库。这本手册记录我怎么用，也记录踩过的坑。**

---

## 为什么有这本手册

市面上 Codex 教程大多是程序员写给程序员的。但 Codex 真正的用户群，是像我这样**不写代码、却要造东西**的人。

我不是程序员，我是写作者。旅行、音乐、AI、科学，我用 Codex 干这些：

- 把我的文章仓库化、自动化
- 让 GitHub Action 每天替我更新内容
- 一键把想法变成可发布的项目
- 一个人维护 100+ 个仓库

这本手册就是我的一手经验。**每个方法都经过真实使用验证，不是抄来的。**

## ⚡ 快速开始（3 分钟版）

不想看长篇？就这三步：

```
1. 装 Codex（官方 App / CLI）
2. 打开终端，进你的项目目录，敲: codex
3. 说人话:"把这个 README 改得更吸引人"
```

完事。就这么简单。**剩下的都是习惯问题。**

想要完整版：[playbook/full.md](playbook/full.md)（3 分钟版）→ [playbook/mini.md](playbook/mini.md)（一页版）→ [playbook/nano.md](playbook/nano.md)（背下来版）
