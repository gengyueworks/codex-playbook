# A Practical Field Guide to Using Codex Without Writing Code

中文 · [非程序员使用 Codex 的经验手册](README.zh-CN.md)

> Codex is seriously underestimated. It can stay with a project from the first idea to a living public work.

This is a practical field guide for writers, researchers, creators, and other people who have ideas but do not write code.

The guide comes from a Chinese content creator who had used GitHub for years without feeling able to build there. After adopting Codex, the work moved from private ideas into public repositories: essays, people, music, science, automated updates, source collections, and reusable project rules.

The author describes the role this way: a bard in the coder world. Others ship features; this guide shows how a writer can turn stories and ideas into open-source creations.

## What this guide teaches

Codex becomes useful when you can do five things:

1. explain the result you want;
2. put the right material in reach;
3. say what may change and what must stay untouched;
4. check the evidence instead of trusting a completion message;
5. save a useful method for the next task.

The chapters use real author cases: a Codex for OSS application, a GitHub profile count corrected from 84 to 102, 681 saved items narrowed to 22, a daily scientist project, 35 video transcriptions, project rules, and maintenance across more than 100 repositories.
