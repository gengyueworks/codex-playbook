# Codex 实战手册 · 背下来版

> 就这几条。记住它们，你就赢过 90% 的人。

---

## 3 秒版

**Codex = 会说人话的程序员。你说要什么，它干。你是老板。**

## 三条铁律

1. **上下文给全** —— 角色 + 任务 + 背景 + 验收
2. **一步一活** —— 一次对话干一件事
3. **用后验证** —— 它是员工，你是质检

## 三个习惯

1. 每个项目建 `AGENTS.md`（规矩写进去）
2. 常用能力封装成 Skill
3. 定时任务交给 GitHub Action

## 三句话

- 说人话，别整术语
- 不满意就纠正："这个不行，改成那样"
- 它不会读心，你想要什么就明说
