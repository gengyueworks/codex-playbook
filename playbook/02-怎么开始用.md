# 怎么开始用

先把入口和第一件事说清楚，不用看懂任何术语。

## 现在 Codex 在哪

Codex 已经不是单独一个软件了。它现在在 ChatGPT 桌面端里头，是一个可以切换的模式。

做法：去官网下载 ChatGPT 桌面端（Mac 和 Windows 都行），打开之后，左上角有个下拉菜单，能在"ChatGPT 通用助手"和"Codex 开发模式"之间切。日常问问题用通用助手，要它动你电脑上的文件、做项目，就切到 Codex。

界面是三块：左边导航，中间对话，右边是浏览器和终端。你主要跟中间对话区说话，它干的事会在右边显示出来。

## 第一件事：给它一个文件夹

别一上来就想"我要做个什么大项目"。先随便挑一个你本地真实的文件夹——比如一个放周报的目录、一个存资料的文件夹——把它交给 Codex，这就是它的活动范围。

新手最容易犯的错，是一上来就开"完全访问"，让它碰你整个电脑。别。先限定在单个文件夹里，它要碰外面的东西得先问你。等用顺了再放开。

验证装好没，就说一句话：**"列出这个文件夹里现在有什么。"** 它能列出来，说明通道通了。

## 权限怎么设

Codex 能在你电脑上干多少事，由权限档位决定，一共四档：

- **请求批准**：每动一步都问你。最安全，但最烦。
- **审我审批**（推荐）：只有它判断有风险的动作才弹出来问你。日常最实用的一档。
- **完全访问**：不限制，它能碰你电脑上任何文件、任何网络。慎用，新手别开。
- **自定义**：用配置文件精细控制，适合已经知道自己在干什么之后。

大多数人的起点是"审我审批"。它既能干活，又不会背着你删东西。

## 装好之后先试三件事

不用做项目，先感受一下它和聊天框哪里不一样：

1. 让它读一个文件，总结里面讲了什么。
2. 让它按你给的格式，重命名文件夹里几个文件。
3. 让它把一段乱糟糟的文字，整理成带小标题的清单。

做完这三件，你就知道它的手能伸多长、该在哪里给它划界线了。剩下的章节就是教你怎么把界线划清楚、把活儿交得稳。
