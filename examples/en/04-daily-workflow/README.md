# Daily Workflow Exercise

This exercise accompanies Chapter 07. It provides a sanitized GitHub Actions shape without accounts, secrets, or a real publishing target.

## Use it

1. Ask Codex to explain `workflow.yml`, including its trigger, permissions, and steps.
2. Ask it to list the checks for a manual run.
3. Ask it to add safeguards for no-change runs and visible failures.
4. Test in a disposable repository before using a real project.

## Review

- A manual trigger exists.
- Permission scope is explained.
- A failed script cannot silently report success.
- No real secret or private path appears.
