# Application Copy Exercise

This is a sanitized version of the application exercise from Chapter 03. It contains no real account, email, or private application link.

## Use it

1. Read `input/facts.md`.
2. Ask Codex to list gaps and facts that need checking.
3. Ask it to write three English fields under 500 characters each.
4. Keep the draft, character counts, and fact check in `output/`.

## Review

- Every field is under 500 characters.
- Every number traces back to `input/facts.md`.
- No account, email, or unverified impact was added.
- The output lists decisions that still need human review.
