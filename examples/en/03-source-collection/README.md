# Source Collection Exercise

This exercise simulates narrowing a large collection to a useful reading list, using three public-safe sample records.

## Use it

1. Count records and fields in `input/sample-bookmarks.json`.
2. Filter for Codex tutorials, practice, workflows, Skills, and automation.
3. Keep the original URL and a reason for each selection.
4. Write the result to `output/reading-list.md`.

## Review

- The raw JSON is unchanged.
- Every selected item has an original URL, category, reason, and check date.
- Unavailable links are marked for review rather than summarized without evidence.
