# First Complete Task

This exercise accompanies Chapter 02. Inputs are under `input/`; the output belongs under `output/`.

## Use it

1. Open this directory as the Codex project folder.
2. Read `playbook/en/02-first-complete-task.md` in the repository.
3. Give Codex the read-only planning request first, then the full assignment.
4. Open the output and compare it with the original material.

## Goal

- Keep original material separate from output.
- Preserve the source of each fact.
- Mark missing information as “Not provided”.
- Perform a small human review.

The output directory does not contain a prepared answer.
