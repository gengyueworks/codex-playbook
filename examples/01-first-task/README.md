# 第一个完整任务练习

这个练习配套教程第 02 章。输入材料在 `input/`，输出文件在 `output/`。

## 使用方法

1. 把本目录作为 Codex 的项目文件夹打开。
2. 阅读仓库中的 `playbook/zh/02-第一次让-Codex-把一件事做完.md`。
3. 先交出“只读并给计划”的第一段，再交出完整任务。
4. 打开输出文件，比较原始材料和输出目录。

## 练习目标

- 区分原始材料和输出目录。
- 保留每条信息的来源。
- 把缺失信息标成“未提供”。
- 亲手完成一次最小检查。

`output/` 只保留目录说明，不预先放答案。答案应该由你在练习过程中生成。
