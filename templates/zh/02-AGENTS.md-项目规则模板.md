# 项目规则模板

把一次性要求留在当前任务里，把长期有效的要求放进这份文件。文件放进项目后，先让 Codex 说明它是否找到了这份规则。

```markdown
# 项目规则

## 项目说明

- 项目名称：
- 面向读者：
- 成品放在哪里：

## 内容习惯

- 使用的语言：
- 语气和长度：
- 标题格式：
- 日期和数字如何核对：
- 链接如何处理：

## 文件习惯

- 原始材料目录：
- 成品目录：
- 哪些文件只读：
- 哪些文件不能删除：

## 交付检查

- [ ] 列出创建和修改的文件
- [ ] 原始材料没有被改动
- [ ] 链接可以打开
- [ ] 数字、日期和引用有来源
- [ ] 展示 diff

## 需要人工确认

- 发布或推送
- 删除文件
- 批量修改
- 公开私人信息
- 扩大账号权限
```
