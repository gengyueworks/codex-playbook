# Skill 模板

先用自然语言跑通一项重复工作，再把真实步骤填进来。

```markdown
# {Skill 名称}

## 一句话说明

这个 Skill 帮我把什么事情做完：

## 什么时候使用

适用场景：
不适用场景：

## 需要的输入

- 材料路径：
- 背景信息：
- 必须保留的事实：
- 目标读者：

## 操作步骤

1. 读取并检查输入。
2. 列出已知信息和待确认问题。
3. 先输出结构，等待确认。
4. 生成交付物。
5. 检查事实、链接、格式和隐私。
6. 汇报文件、检查结果和未决事项。

## 禁止事项

- 不覆盖原始材料。
- 不把缺失信息写成确定事实。
- 不在没有确认时发布或推送。

## 输出

- 成品位置：
- 来源说明位置：
- 检查报告位置：

## 测试记录

- 测试日期：
- 使用的输入：
- 发现的问题：
- 已修正的规则：
```
