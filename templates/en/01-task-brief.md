# Task Brief Template

Fill this in before giving the task to Codex. Write “to confirm” when information is missing.

```text
I want to complete:

Background:

Files or result I want to keep:

Material I already have:

Locations Codex may read:

Locations Codex may change:

Facts that must remain:

Things Codex must not do:

I will check the result by:

First read the material and give me a plan. Do not modify files until I review it.
```

At handoff, add:

```text
Report every file created or modified, why it changed, checks run and their results, decisions still needed, and any failure list with a next step.
```
