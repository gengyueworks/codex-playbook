# Automation Checklist

Answer each item before leaving the process unattended.

- [ ] The manual process has run successfully once.
- [ ] Input, output, and script locations are clear.
- [ ] A test date or dry-run mode exists.
- [ ] A manual trigger exists.
- [ ] Failures leave logs or a failure list.
- [ ] Repeated runs do not overwrite finished work.
- [ ] No-change runs do not create empty commits.
- [ ] Stale input produces a visible warning.
- [ ] Permissions cover only the required write scope.
- [ ] Secrets and private data stay out of the repository.
- [ ] Human spot checks are scheduled after launch.
