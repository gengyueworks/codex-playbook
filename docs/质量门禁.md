# 教材质量门禁

交付前在仓库目录运行以下检查：

```bash
git diff --check
python3 scripts/quality_gate.py
```

另外运行一次项目维护者的敏感措辞检查，确保成品没有带有贬义的“照搬”表达。

## 章节门槛

- [ ] 中文 10 章全部存在。
- [ ] 英文 10 章与中文一一对应。
- [ ] 每章都有具体动作、可见结果、排查方式或验收标准。
- [ ] 案例来自作者真实经历或明确标为脱敏练习。
- [ ] 没有账号、密钥、私人邮箱和本地私人路径进入示例成品。
- [ ] README 目录按第一章到第十章排列。
- [ ] Markdown 表格的行之间没有空行。
- [ ] 中文正文使用中文标点。
- [ ] 链接目标真实存在，中文文件名链接已经 URL 编码。

## 交付证据

最后报告必须包括：

1. 改动文件数量；
2. 中英文章节数量；
3. 练习和模板数量；
4. `git diff --check` 结果；
5. 链接检查结果；
6. 尚未推送 GitHub 的本地状态。
