# Sources and Writing Notes

## Material used for this edition

This edition was informed by the handoff brief, the Codex Orange Book, 35 course transcripts, a curated set of community tutorials, and the author’s own project records.

The local handoff files were used as private research material and were not copied into the public repository.

## Case policy

The source material provides methods and questions. The chapters use the author’s own experiences for the main cases, including the Codex for OSS application, GitHub profile maintenance, source collection, daily publishing, transcription work, project rules, and maintenance across many repositories.

Third-party examples are not used as the central case studies.

## Version

- Edition date: 2026-08-11
- Positioning: a practical field guide for non-programmers using Codex
- Chinese path: the main experience narrative
- English path: a matching public reading path

Codex, desktop applications, automation, and GitHub interfaces change over time. Check current official documentation for product details. The durable habits in this guide are to read the material first, state the result, work in small steps, leave evidence, and save useful methods.
